# Neural Network Forward Propagation using NumPy

## Overview

This project demonstrates the implementation of **Forward Propagation in an Artificial Neural Network (ANN)** using Python and NumPy.

Forward Propagation is the process through which input data passes through the neural network layers to generate an output prediction.

The implementation manually performs weight and bias initialization, matrix multiplication, weighted sum calculation, and activation function application without using high-level Deep Learning frameworks.

## Neural Network Architecture

The implemented neural network consists of:

- **Input Layer:** 2 input features.
- **Hidden Layer:** 2 neurons.
- **Output Layer:** 1 neuron.

The network processes multiple input samples and generates corresponding output predictions.

## Key Features

- Manual initialization of weights and biases.
- Matrix multiplication using NumPy.
- Implementation of the Sigmoid activation function.
- Hidden layer weighted sum calculation.
- Hidden layer activation computation.
- Output layer forward propagation.
- Final prediction generation.
- Step-by-step execution and output visualization in the terminal.

## Mathematical Concepts

### 1. Weighted Sum Calculation

The weighted sum of the input features is calculated as:

Z = XW + b

Where:

- X: Input feature matrix.
- W: Weight matrix.
- b: Bias vector.
- Z: Weighted sum.

### 2. Sigmoid Activation Function

The Sigmoid function introduces non-linearity into the neural network.

σ(x) = 1 / (1 + e⁻ˣ)

Its output ranges between 0 and 1.

### 3. Forward Propagation

The network performs the following operations:

**Hidden Layer:**

Z₁ = XW₁ + b₁

A₁ = Sigmoid(Z₁)

**Output Layer:**

Z₂ = A₁W₂ + b₂

A₂ = Sigmoid(Z₂)

The final output A₂ represents the predictions generated by the neural network.
